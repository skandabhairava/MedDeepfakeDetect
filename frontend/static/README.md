# Static Assets

This folder contains static assets that will be served from the root of your site.

## Favicon
Place your favicon files here:
- `favicon.png` - Default favicon
- `favicon.ico` - IE fallback
- `apple-touch-icon.png` - Apple touch icon

## Other Static Files
- Images
- Fonts
- Documents
- Any other static files

These files will be available at the root URL, e.g.:
- `/favicon.png`
- `/images/logo.png`
- `/documents/manual.pdf`
